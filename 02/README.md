### 1.1 Definisi Proses dan Manajemen Proses

Dalam konteks sistem operasi dan komputasi dasar, **proses** didefinisikan sebagai program yang sedang dalam tahap eksekusi. Ketika sebuah aplikasi dijalankan, instruksi program dari disk diinstansiasi dalam RAM dan diabstraksi oleh sistem operasi melalui struktur data seperti _Process Control Block_ (PCB) alokasi memori, registrator, stack, serta thread. Penjadwal CPU (_CPU Scheduler_) mengatur bagaimana proses-proses ini mendapatkan alokasi siklus prosesor secara bergantian.
